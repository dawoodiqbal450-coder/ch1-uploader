Privacy Policy

ch1-uploader · last updated 2 September 2026

Who this covers

ch1-uploader is a personal automation operated by a single individual for their own YouTube channel. There are no other users. The only Google Account it ever connects to is the owner's own account, which they authorize themselves.

What data is accessed

The application requests exactly one Google API scope:

  • https://www.googleapis.com/auth/youtube.upload — upload a video to the owner's own YouTube channel.

It does not request access to email, contacts, files, profile data, watch history, or any other Google service. It cannot read existing videos, comments, or analytics.

What is stored

  • An OAuth refresh token for the owner's own account, held as an encrypted secret in the owner's private GitHub repository and used only to obtain short-lived upload tokens.
  • A small database of which of the owner's own videos have already been published, so the same one is not posted twice. It contains video identifiers, titles, view counts and timestamps — no personal data.

What is not done

  • No data is sold, rented, or shared with third parties.
  • No advertising, profiling, tracking, or analytics of any kind.
  • No data is collected from anyone other than the owner.
  • Google user data is never used to train any AI or machine-learning model.

Retention and deletion

The refresh token remains valid until the owner revokes it. Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately and permanently ends the application's access. Deleting the repository erases the stored token and the publication record.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions about this policy can be sent to the developer contact address registered on the Google Cloud project for this application.
